# Terraformer

Mobile game UI prototype — a rotatable hex-tile planet with resource meters, event alerts and an action dock.

Imported from the Figma Make project
[Mobile Game UI Mockup](https://www.figma.com/make/yMxbraKBNFgvhUozCwi0JR/Mobile-Game-UI-Mockup).

## Develop

```sh
npm install
npm run dev      # local dev server
npm run build    # typecheck + production build
```

Stack: React 19, TypeScript, Vite, Tailwind CSS 4.
